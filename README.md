# BrickLedger

BrickLedger is a smart, secure, and private mobile app for property investors to manage their property portfolios, financial tracking, and strategic tax planning. Built with React Native (Expo) and TypeScript, it supports both iOS and Android platforms.

## MVP Features
- Supabase authentication and database
- User onboarding and setup
- Dashboard with portfolio overview
- Entity and property management
- Mortgage, loan, and account management
- Basic financial metrics
- Security and privacy settings
- Unified, modern, responsive UI

## Getting Started

### Install dependencies
```
npm install
```

### Run the app
- For iOS: `npm run ios`
- For Android: `npm run android`
- For Web: `npm run web`

## Folder Structure
- `/app` - Main application code
- `/components` - Shared UI components
- `/properties` - Property management
- `/accounts` - Financial accounts and loans
- `/dashboard` - Portfolio overview
- `/auth` - Auth
